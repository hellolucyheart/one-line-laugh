One funny line: a single sentence of at most 200 characters. This entry's line is about finally reaching inbox zero — and what Gmail does the very second you get there.

## Run it

```sh
python3 main.py
```

It validates the line (one sentence, 1–200 characters) and writes it to `/output/entry.txt`.
